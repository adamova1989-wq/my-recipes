Merge request (на GitHub — Pull Request) — это просьба влить мою ветку в main. Ревью нужно, чтобы напарник проверил изменения и нашёл ошибки до того, как они попадут в общий код.

Почему был конфликт: мы с Зариной работали в разных ветках, но обе изменили первую строку README.md. Когда моя ветка влилась в main, у Зарины оказалась другая версия той же строки, и Git не смог сам решить, какую оставить.

Как решили: git switch main -> git pull -> git switch add-food -> git merge main -> в README оставили одну общую строку и удалили маркеры <<<<<<< ======= >>>>>>> -> git add README.md -> git commit -> git push -> PR стал зелёным, нажали Merge.
