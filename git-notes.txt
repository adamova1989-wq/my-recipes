 HEAD detached - команда позволяет на старый коммит, но ни находиться ни в какой ветке 
 git revert -отмена коммита последнего, а предыдущие остаются
 git switch -c -создать новую ветку и перейти в нее
 git merge- влить изменения из другой ветки, в той где я сейчас
